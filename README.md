This project evaluates the efficiency of ML models in customer purchase behaviour prediction based on e-commerce transactional data. Customer-level behavioural feature is engineered using the Online Retail II dataset and examined with the help of EDA. A few classification models like “Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting” are trained and tested. Results show that ensemble models are better at prediction. The study finds that machine learning provides plausible and accurate answers to understanding and predicting customer purchasing behaviour.
